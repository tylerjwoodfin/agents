# JavaScript and TypeScript

- Use the package manager this repository already uses. Match the lockfile that is committed (`package-lock.json`, `yarn.lock`, or `pnpm-lock.yaml`).
- Stay on the language the repository already uses. Do not convert JavaScript to TypeScript, or the reverse, unless asked.
- Follow the module style of the file you are editing (ESM or CommonJS).
- Add a dependency only when the task cannot be done with what is already installed.

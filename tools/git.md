# Git

- Follow this repository's `AGENTS.md` for branch names and which branch a pull request targets.
- When the change implements a TJW ticket, start the commit subject with `TJW-###:`.
- Do not commit unless asked. Do not push unless asked.
- Do not skip hooks (`--no-verify`, `--no-gpg-sign`).
- Do not force-push the default branch.
- Do not commit secrets (`.env`, credentials, tokens).
